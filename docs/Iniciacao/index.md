# Iniciação

> Objetivo: Definir o escopo inicial do projeto e alinhar os objetivos principais.

## Principais atividades

* Identificar os principais requisitos do sistema VerificaEstagio.
* Estimar prazos e responsabilidades para o desenvolvimento do backend.
* Avaliar riscos de conformidade, usabilidade e integração de dados.
* Documentar a visão do produto e os casos de uso principais.
* Produto principal: visão do projeto, escopo inicial e alinhamento entre equipe e objetivos.

## Escopo definido até o momento

- Cadastro de usuários, empresas e instituições.
- Registro de estágios e contratos.
- Upload de contrato em PDF.
- Análise automática de conformidade.
- Geração de pendências e relatórios.
- Emissão de parecer institucional.

## Lacunas restantes

- Frontend de usuário e interface de visualização de resultados.
- Extração real de dados via OCR para contratos.
- Notificações automáticas e comunicados para alunos/empresas.
- Fluxo de confirmação de usuário por e-mail.
- Representação de limite de prazo, custo e risco em documentos de planejamento.
